# IMDB Sentiment Classifier (BERT + Gradio)

A professional-grade sentiment analysis application that classifies movie reviews as **Positive** or **Negative** using a fine-tuned BERT model. This repository includes the full training pipeline and a real-time web interface built with Gradio.

---

## 🚀 Overview
This project leverages **BERT (Bidirectional Encoder Representations from Transformers)** to understand the semantic nuances of movie reviews. Unlike traditional Bag-of-Words models, BERT looks at the context of words in both directions, leading to significantly higher accuracy on complex reviews.

### Features
*   **Deep Learning Backend:** Powered by `bert-base-uncased`.
*   **Interactive UI:** A Gradio-based web dashboard for testing custom text.
*   **High Accuracy:** Fine-tuned specifically on the 50k IMDB dataset.
*   **Ready for Deployment:** Easy-to-follow structure for local or cloud hosting.

---

## 🛠️ Tech Stack
*   **Language:** Python 3.9+
*   **Model:** Hugging Face Transformers (BERT)
*   **Deep Learning:** PyTorch
*   **UI Framework:** Gradio
*   **Data Handling:** Pandas, Scikit-learn
